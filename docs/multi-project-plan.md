# 多工程首页实施计划

目标：启动后先显示工程列表，可创建、导入、打开和删除工程，并在首页使用跨工程共享的字体库和图片库。

1. 在现有 SQLite 文件中增加 `projects` 表，保存完整书稿 JSON 和列表摘要；复用原有资源表，保持已导入资源可用。测试创建多个工程、重启读回、更新、删除及资源库互不影响。
2. 增加 Tauri 工程命令。导入 TXT、EPUB 和 JSON 后登记为新工程；编辑器的“保存项目”写回工程数据库，另保留导出 JSON 文件的入口。
3. 增加参照苹果图书的深色封面书架，提供工程、字体库、图片库三个标签。创建工程先填写书名、作者、语言；封面可在编辑器中稍后上传。编辑器返回首页时处理未保存修改；首页与编辑器资源库读取同一 SQLite 数据。
4. 验证前端构建、Rust/TypeScript 测试、窗口导航和 macOS 安装包。Windows 安装包由仓库工作流构建。
